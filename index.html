Research Specification & Technical Whitepaper

Solving the Black-Box Paradox in Sub-Second Financial Rails

Author: SentinelPay Engineering Lab · Academic Reference: MAI412-2 Full Stack Development

In modern financial technology, instant payment mechanisms such as India’s Unified Payments Interface (UPI) and the US FedNow system settle transactions irreversibly in fewer than two seconds. While this speed is a triumph of digital infrastructure, it fundamentally changes the cybersecurity equation: once funds depart the debtor's account, recovery via traditional recall is virtually zero.

The Limitations of Legacy Heuristic Rules

Traditional banking systems rely heavily on deterministic if-then rule engines (e.g., IF transaction_amount > 50000 AND time == nocturnal THEN flag). These legacy systems suffer from two systemic failures:

  • High False-Positive Friction: Upwards of 85% of transactions halted by traditional rules are legitimate users making atypical purchases, eroding consumer trust.
  • Vulnerability to Low-and-Slow Attacks: Modern syndicates deliberately orchestrate transactions just below static threshold values to bypass manual rules entirely.
"Machine learning without explainability creates a liability for chartered banks. If an autonomous model rejects an innocent customer's transaction without explainable recourse, it violates statutory fair lending and transparent banking directives."

The SentinelPay Architecture: Fusion of ML & Generative XAI

SentinelPay addresses this dilemma by deploying a bifurcated inference pipeline:

  1. Lightweight Anomaly Detection at the Edge: A sub-50ms ensemble model assigns a risk index $R \in [0, 1]$ to streaming JSON payloads using isolated decision trees.
  2. Localized Additive Explanations (SHAP): If $R \ge 0.65$, feature attribution vectors isolate the highest contributing anomalies (e.g., rapid IP geodelta or deviation from user baseline velocity).
  3. Generative Narrative Synthesis: The SHAP vector is mapped into an automated natural language narrative, supplying compliance officers with immediate context rather than cryptic numerical matrices.
